# Data

The datasets are intentionally not committed to this repository.

## Task 1 — Hyperspectral land-cover classification

Place the project dataset at:

```text
data/data-1.csv.gz
```

The dataset used in the executed notebook contains **215,604 pixel observations**, **218 spectral reflectance bands**, spatial coordinates (`p_x`, `p_y`), and eight land-cover classes. It is derived from EnMAP hyperspectral imagery from Tyrol, Austria.

EnMAP example data: https://www.enmap.org/data_tools/exampledata/

> To reproduce the notebook exactly, use the same preprocessed/project dataset used for the coursework.

## Task 2 — Neural feature selection

Place the course-provided dataset at:

```text
data/data-2.csv.gz
```

It contains **683 trials** and **11,190 neural spike-count features** (2,238 neurons × 5 time bins), with a binary left/right choice label.

This dataset was provided for the course and is not redistributed here.
